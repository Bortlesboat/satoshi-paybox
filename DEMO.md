# Demo video script (30–45 s, post to X)

Record Claude.ai or Grok with the PayBox connector connected and the Satoshi plugin enabled (app.paybox.sh/plugins → Unofficial plugins).

1. **0–5 s** Title card or caption: "Should I send Bitcoin now? Ask your agent." Show the PayBox plugin list with Satoshi enabled.
2. **5–15 s** Prompt: "I need to send 0.01 BTC today. Send now or wait?" Satoshi's answer appears: the fee table in sats and dollars, the mempool depth, and the SEND NOW / WAIT verdict with the savings.
3. **15–22 s** Prompt: "How busy is the Bitcoin network right now?" The snapshot shows height, unconfirmed txs, MB queued, blocks to clear.
4. **22–35 s** Prompt: "Fees aren't worth it for $25. Pay Sam in Bitcoin on Base instead: 0x…" Satoshi prepares the cbBTC transfer, shows the BTC amount, USD value and the on-chain fee avoided. The PayBox approval panel opens, passkey tap, confirmed on Base. Show the Basescan transaction.
5. **35–45 s** End card: "Satoshi: a PayBox plugin. Fee intelligence from the mempool. Settle in Bitcoin on Base with one passkey." Tag @PayBox @moonpay. Repo link.

Suggested X post text:

> Built Satoshi for the @PayBox hackathon: ask your agent "send Bitcoin now or wait?" and it reads the live mempool, prices every fee tier, and answers with the savings. When fees make a small payment silly, it settles in Bitcoin on Base (cbBTC) with one passkey. Free tools + one money tool, no keys ever touched. @moonpay
